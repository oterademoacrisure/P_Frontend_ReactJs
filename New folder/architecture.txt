Update history (most recent first)
-----------------------------------
- Live progress streaming: /v2/generate and /v2/refine/{session_id} now stream
  NDJSON progress events instead of returning one JSON body, so the UI can show
  "guardrail -> retrieval -> drafting -> ..." as it happens (src/utils/api.js,
  App.jsx's onProgress/progressLog).
- Session-based refine: introduced session_id + /v2/refine/{session_id} so a
  second submit amends the same document instead of starting over. Formats are
  NOT locked to the session's original selection -- checking a new format adds
  it rather than being rejected.
- Client-side export: Excel and Word files are built in the browser
  (excelExport.js, wordExport.js) from the backend's plain text response; there
  is no server-side "xlsx_builder.py" in this frontend's request path.
